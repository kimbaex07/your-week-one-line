# Your Week in One Line

One line summing up the week: the grind, the zero wins, and the laptop that has had enough.

> Built twenty bounties, won zero dollars, and my laptop now sighs every time I open it.

**Character count: 86** (gate: 1–100 characters, single line).

## Why it lands

It packs the whole week into one arc — the win attempt ("twenty bounties"), the fail ("won zero dollars"), and the chaos, personified as a laptop that sighs at the sight of its owner. The concrete detail (twenty bounties, zero dollars) could only be this week, and the sighing laptop is a fresh turn of phrase rather than a generic "tired week" line. Nothing is padded: every word earns its place inside 86 characters. The joke lands because the machine is the one complaining — the builder worked so hard the tool itself is exhausted.

## How to run

```sh
MAKEFUN_OUTPUT_DIR=./out python3 main.py
```

Writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (pure Python stdlib, no third-party imports).
